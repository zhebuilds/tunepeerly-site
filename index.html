你的音乐，
在你的设备间流动

声渡是免账号、点对点加密互联的本地音乐播放器。电脑和手机在同一个 Wi-Fi 里配对一次，就能互相播放、下载对方存着的歌——不上传云端，也不用注册。

功能

简单，私密，只属于你

歌在哪台设备上，就从哪台设备听。没有服务器替你保管音乐，也没有账号要记。

不用账号

打开就能用。没有注册、登录，也没有云端账户。

6 位码配对

一台显示配对码，另一台输入。码只用一次，90 秒内有效；配好后互相记住。

端到端加密

设备之间只走 TLS 1.3，只认配对时保存的密钥，别人插不进来。

互听、互下

播放已配对设备上的任意一首歌，也可以把原文件下载到本机。

手动同步

喜欢的歌和外观按设备「发送」或「覆盖」，接收方可选接受、询问或拒绝。

出门也能连

可选用你自己部署的中继连回家里的设备；中继只转发，读不到内容。

另有：滚动歌词、歌单、中英文与深浅色主题、无痕模式；Windows 迷你播放器与任务栏按钮；Android 锁屏和通知栏播放控制。

使用

三步开始听

  1. 安装

    在电脑上装 Windows 版，在手机上装 Android APK。

  2. 配对

    两台设备连同一个 Wi-Fi，打开「发现附近设备」，一台显示配对码，在另一台输入。

    481275

  3. 播放

    对方的歌出现在你的曲库里，直接点开就能听，想留着就下载到本机。

局域网里找不到对方？用手机开个热点，让设备都连上它再试。

安全与隐私

数据只在你的设备之间

声渡没有中心服务器。连接、配对和存储都按“默认不信任”设计，具体细节写在仓库的 SECURITY.md 里。

  • 配对码不上网配对码用 SPAKE2 核对，本身不在网络上传送；输错 3 次，配对暂停 1 分钟。
  • 连接双向认证TLS 1.3，双方都要证明身份，只接受配对时记住的公钥。
  • 曲库数据库加密SQLCipher 加密；密钥在 Windows 上由 DPAPI 保护，在 Android 上由 Keystore 封装。
  • 中继看不到内容中继只在已配对设备间转发密文，不能配对；它能看到 IP、在线时间和流量大小。

核对 Windows 安装包

在安装包所在文件夹打开 PowerShell，算出 SHA256，和发布页上这个文件显示的 SHA256 对照，一致再安装。

Get-FileHash -Algorithm SHA256 .\TunePeerly-0.8.0-alpha.1-x64-Setup.exe

安装包目前没有代码签名，Windows SmartScreen 可能会拦一下：确认来源无误后，点「更多信息」→「仍要运行」。

核对 Android APK 签名

官方 APK 的签名证书 SHA-256 指纹：

f02eb081eabeb8b1a4b77ab1d4a7325722d6cda978226066e15ef423e759f2f0

用 Android SDK 的 apksigner 检查，输出里 certificate SHA-256 digest 应与上面一致：

apksigner verify --print-certs TunePeerly-0.8.0-alpha.1-arm64-v8a.apk
