TunePeerly is an account-free local music player that links your devices peer-to-peer, end-to-end encrypted. Pair your computer and phone once on the same Wi-Fi, then play or download the songs stored on each other — no cloud upload, no sign-up.

Features

Simple, private, and yours

Songs play from whichever device they live on. No server keeps your music, and there is no account to remember.

No account

Open it and go. No sign-up, no login, no cloud account.

Pair with a 6-digit code

One device shows a code, the other types it. Single use, valid for 90 seconds; paired devices remember each other.

End-to-end encrypted

Devices talk only over TLS 1.3 and accept only the keys saved when pairing.

Play and download

Stream any song from a paired device, or download the original file to this one.

Manual sync

Send or Override liked songs and appearance per device; the receiver can accept, ask, or deny.

Reach home from anywhere

Optionally use a relay you host yourself. It only forwards data and cannot read it.

Also: synced lyrics, playlists, Chinese and English, light and dark themes, incognito mode; a mini player and taskbar buttons on Windows; lock-screen and notification controls on Android.

How it works

Three steps to listen

  1. Install

    Install the Windows app on your computer and the Android APK on your phone.

  2. Pair

    Join the same Wi-Fi and turn on Discover nearby devices. One shows a code; type it on the other.

    481275

  3. Play

    Their songs show up in your library. Tap to play, or download to keep a copy.

Can't find each other on the LAN? Turn on your phone's hotspot and connect both devices to it.

Security & privacy

Your data stays between your devices

There is no central server. Pairing, connections and storage assume nothing is trusted by default. Details are in SECURITY.md in the repository.

  • The code never travelsThe pairing code is checked with SPAKE2 and never sent over the network. After 3 wrong tries, pairing pauses for 1 minute.
  • Mutual authenticationTLS 1.3 where both sides prove who they are, accepting only the public key saved at pairing.
  • Encrypted libraryThe database uses SQLCipher; its key is protected by DPAPI on Windows and wrapped by the Android Keystore.
  • Relays can't readA relay only forwards ciphertext between paired devices and can't pair. It can see IPs, online times and traffic volume.

Verify the Windows installer

Open PowerShell in the download folder, compute the SHA256 and compare it with the SHA256 shown for this file on the release page. Install only if they match.

Get-FileHash -Algorithm SHA256 .\TunePeerly-0.8.0-alpha.1-x64-Setup.exe

The installer is not code-signed yet, so Windows SmartScreen may warn you. If the file checks out, choose More info → Run anyway.

Verify the Android APK

SHA-256 fingerprint of the official APK signing certificate:

f02eb081eabeb8b1a4b77ab1d4a7325722d6cda978226066e15ef423e759f2f0

Check with apksigner from the Android SDK; the certificate SHA-256 digest line should match:

apksigner verify --print-certs TunePeerly-0.8.0-alpha.1-arm64-v8a.apk
